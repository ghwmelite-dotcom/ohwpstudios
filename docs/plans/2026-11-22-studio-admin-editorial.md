# Studio CMS alignment and editorial launch

## Outcome

Keep the premium five-section homepage and all existing pages, chat, forms, portal and security controls. Make the admin describe and edit the redesigned content it actually controls. Populate an isolated preview with six substantive articles; production remains unchanged until review and deployment approval.

## CMS contract

- Introduce typed `studio_` content keys with the currently approved copy as defaults. Read only these keys for redesigned page copy so historical placeholder seeds cannot replace the new design.
- Homepage editor covers hero, three service disciplines, guided builds, studio story and contact invitation. About editor edits the redesigned masthead and story. Footer editor edits its invitation. Render CMS prose as escaped text, with line breaks/paragraphs preserved.
- Preserve legacy content records and management tools. Clearly distinguish retained catalogue/team/value records and configuration-owned branding/contact destinations from the editable premium page copy.
- Keep session authentication, CSRF, tenant/visitor ownership and rate limits unchanged. Validate new inputs and use prepared statements.

## Editorial launch

Six distinct search intents: choosing a Ghana business website versus application; writing a software project brief; guided builds with AI coding tools; reliable Ghana mobile-money integration; TradingView indicators versus MT5 bots; and useful business AI assistants. Each article has a direct answer, practical decision guidance, FAQs, primary references, descriptive internal links and a Telegram quote handoff. No invented client results, model performance, price ranges, search-volume claims or guaranteed rankings.

An authenticated, CSRF-protected starter-pack action adds missing articles as drafts. It never overwrites existing articles. Preview articles may be published only in the isolated local database for review. This is a one-time editorial pack, not automatic scheduled publishing.

## Publishing and discovery

Fix draft visibility in admin; ensure edit/publish controls work without stripped inline handlers. Preserve public published-only queries. Correct article publisher/author schema and canonical URLs; add visible breadcrumbs, reading time and clear attribution. Retain current blog search/filter behaviour and dynamic published-post sitemap. Do not claim FAQ rich-result eligibility or AI citation guarantees.

## Evidence gate

Tests for CMS persistence/escaping and fallback, draft isolation, import idempotency and validation; actual isolated admin login, saves and public rendering; blog creation/edit/publish/draft handling; article links/schema/sitemap; mobile review; existing regression suite, build and zero-finding secret scan. Save preview links, screenshots and any untested limits. No production writes or deployment during preview work.
